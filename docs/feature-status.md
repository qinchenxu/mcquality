# 功能状态

本文档用于记录当前仓库中已经落地的功能、部分完成的功能，以及仍未开始或尚未接通的功能。

更新原则：

- “已完成”指代码已经接入主流程，并能在当前版本中直接使用。
- “部分完成”指已经有数据结构、界面骨架或占位实现，但还没有完整闭环。
- “未完成”指仍停留在规划或设计阶段。

## 已完成

### 核心品质系统

- 合成产物会自动生成装备品质。
- 战利品掉落会自动生成装备品质。
- 新生成装备会把 rarity、affixes、active_skill、passive_effects 写入 CUSTOM_DATA 的 v2 根结构。
- 新生成装备会按武器、护甲、工具分池抽取 starter affix 实例。
- 旧版仅含 quality / active_skill / passive_effect 标签的装备仍可兼容读取。
- tooltip 与 lore 会显示品质、词条数和主动技能摘要。

### 客户端详情面板基础能力

- 主手持有受支持武器时，可按 I 键打开装备详情面板。
- 详情面板已经显式关闭 Minecraft 默认背景模糊。
- 详情面板支持基础的双栏布局。
- 详情面板支持自动换行。
- 详情面板支持滚轮滚动。
- 详情面板支持方向键和翻页键滚动。
- 详情面板支持基础滚动条显示。

### 详情面板已接入的真实数据

- 可显示当前装备名称。
- 可显示当前品质稀有度。
- 可显示装备类型。
- 可显示当前词条数量摘要。
- 可显示当前物品上已经存在的属性修正列表。
- 可显示当前装备的 affix 实例列表。
- 可显示结构化主动技能数据与兼容旧标签技能数据。

### 第一版技能与被动数据

- 代码中已经定义主动技能枚举：弧光斩、守御脉冲、震荡爆发。
- 代码中已经定义被动效果枚举：稳固锋刃、迅击节奏、巨力握持、破势压制。
- 已有技能定义 JSON：弧光斩、守御脉冲、震荡爆发。
- 已有 starter affix 定义 JSON：武器、护甲、工具三类基础词条。
- 新生成的高品质武器会按当前规则写入结构化主动技能数据。
- 新生成的武器会写入结构化被动效果列表。
- 详情面板会读取并展示主动技能名称、说明、触发方式、冷却时间和粒子风格文本。
- 详情面板会读取并展示被动效果名称、说明和数值强度。

## 部分完成

### 主动技能系统

- 已完成：技能枚举、基础文本、面板展示、结构化技能数据写入。
- 已完成：右键触发后的服务端判定。
- 已完成：弧光斩、守御脉冲、震荡爆发三种第一版执行模板。
- 已完成：原版冷却系统接入。
- 已完成：技能对实体伤害、护盾和击退的真实影响。
- 未完成：更复杂的技能数值平衡与多人环境专项验证。

### 被动效果系统

- 已完成：被动效果枚举、文本、面板展示、结构化数据写入。
- 未完成：被动效果对属性或战斗流程的真实结算。
- 未完成：被动效果的触发条件、持续时间、内置冷却等机制。

### 详情面板 UI

- 已完成：基础面板、标题栏、内容区、自动换行、滚动。
- 已完成：解决默认背景模糊问题。
- 未完成：更成熟的视觉风格与最终版布局。
- 未完成：滚动条拖拽。
- 未完成：分页、分类切换或选项卡。
- 未完成：不同分辨率下的专门适配验证。

### 粒子系统

- 已完成：粒子注册、自定义 provider、粒子 JSON 和贴图资源。
- 已完成：技能释放时的真实粒子效果。
- 已完成：服务端到客户端的粒子同步，当前走原版粒子广播链路。

### 网络层

- 已完成：网络注册入口骨架。
- 已完成：第一版闭环不依赖自定义 C2S/S2C 包，主动技能触发走原版交互同步，粒子走原版粒子包。
- 未完成：主动技能状态、自定义多人同步或更复杂状态复制消息。

## 未完成

### 词条系统重构

- 当前只完成 starter affix 池，还没有更完整的 affix 数量、冲突组和高阶分层规则。
- 还没有冲突组、词条权重、词条品质等机制。

### 技能真实触发链路

- 第一版技能触发链路已接通，但仍缺少更复杂的技能模板、更多触发方式和专项平衡验证。

### 被动效果真实结算

- 还没有把被动效果接入属性聚合。
- 还没有把被动效果接入事件触发或战斗判定。

### 粒子与表现层

- 第一版粒子链路已接通，但仍缺少更细化的视觉差异、贴图质量和持续型表现。

### 数据驱动资源

- 已有 starter skill / affix JSON 与 reload listener。
- 还没有更完整的 passive 定义 JSON、复杂条件加载和更丰富的数据 schema。

### 兼容与验证

- 还没有旧版仅含 quality 标签装备的迁移逻辑。
- 还没有系统化的单人验证清单落地。
- 还没有多人环境验证。
- 还没有完整的平衡性验证。

## 当前结论

当前版本已经进入第一版可玩闭环：

1. 新装备会生成 rarity + affix + skill / passive 的结构化数据。
2. 主动技能可以右键真实释放，并对战斗结果产生影响。
3. 粒子、资源文件和客户端表现已经接通。

现阶段最关键的后续缺口变成了：

1. affix 池仍是 starter 规模，还没有冲突组、完整权重和更复杂的词条品质层。
2. passive 仍停留在结构化与展示层，没有接入真实结算。
3. 还没有多人环境与平衡性专项验证。

## 推荐的下一步

1. 先把 passive 接到真实属性聚合或战斗事件里。
2. 再扩 affix 池、冲突组和更完整的数据驱动 schema。
3. 最后做多人环境、平衡性和表现层专项验证。
